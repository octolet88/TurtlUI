# TurtlUI
A UI mod for hordes.io custom for me. Release is undetermined

## Version List / Changelog

### v1.0.0
- Fresh userscript foundation for TurtlUI.
- Added a turtle launcher button to open/close the TurtlUI menu.
- Added a menu toggle for editable UI mode so movable elements can be repositioned.
- Added persistent saved UI positions with localStorage.
- Added rigid skillbar layout enforcement with exactly 20 slots per row.
